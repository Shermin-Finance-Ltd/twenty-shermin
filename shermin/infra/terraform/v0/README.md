# Terraform — v0 deploy

Brings up the AWS infrastructure for v0 of the Shermin Twenty CRM in the dev account (`992914515467`, eu-west-2). Vanilla Twenty, single-user, single-region, single-AZ — designed to be cheap and easy to throw away.

**Twenty itself is NOT deployed by Terraform.** Terraform brings up the boxes; a separate SSM Run Command deploys Twenty's docker-compose stack onto the EC2. This separation means you can iterate on the Twenty config without re-running Terraform.

## What gets created

| Resource | Notes |
|---|---|
| VPC `10.20.0.0/16`, 2 AZs | Public + private subnets per AZ |
| Internet gateway + route tables | EC2 in public subnet (no NAT — saves £28/month) |
| Security groups | `sg-alb` (443 in from 0.0.0.0/0), `sg-ec2` (3000 in from `sg-alb`), `sg-rds` (5432 in from `sg-ec2`) |
| RDS Postgres 16 `db.t4g.small` | Single-AZ, 20 GiB gp3, 14d backups, encrypted |
| EC2 `t4g.medium` Amazon Linux 2023 ARM64 | Public subnet, IAM role with Secrets Manager + S3 + SSM |
| ALB | HTTPS listener with self-signed cert generated by Terraform |
| S3 bucket | Twenty attachments, block all public, SSE-S3, versioning |
| Secrets Manager | DB password (auto-generated), Twenty `APP_SECRET` (auto-generated) |
| KMS | AWS-managed keys only for v0 |
| CloudWatch log group | `/twenty-shermin/v0` |

## Prerequisites

- AWS CLI authenticated for the dev account: `aws sts get-caller-identity --profile shermin-dev` should return account `992914515467`.
- Terraform >= 1.13.4 (we have 1.15.0).
- The state backend bucket `stax-development-terraform-state-bucket` already exists in the dev account.

## Apply

```bash
cd shermin/infra/terraform/v0
export AWS_PROFILE=shermin-dev

terraform init -backend-config=env/dev/backend-config.hcl
terraform plan -var-file=env/dev/dev.tfvars -out=v0.tfplan
terraform apply v0.tfplan
```

Apply takes ~15 minutes (RDS takes the longest).

## Destroy

```bash
cd shermin/infra/terraform/v0
export AWS_PROFILE=shermin-dev
terraform destroy -var-file=env/dev/dev.tfvars
```

RDS has `deletion_protection = false` and `skip_final_snapshot = true` for v0 to make destroys clean. Change those when this becomes anything more than throwaway.

## After apply

Run the SSM deploy script to install and start Twenty:

```bash
../../scripts/deploy-twenty.sh
```

Then visit the ALB URL in `terraform output alb_url`, accept the self-signed cert warning, sign up as the workspace admin.

## Cost

About £77/month while running. `terraform destroy` to stop billing — RDS is the biggest cost at ~£24/month, EC2 is ~£22, ALB ~£18.
